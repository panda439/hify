**语料**：《阿Q正传》9 章。用户提供的快照含 322 个段落 ID；排除空白段 C02P030、
网页模板/编者说明 C09P048～054 后，保留 314 段（含结尾写作日期）。不重排已有 ID。
**状态**：AI 初标可用于开发；人工验收集尚未冻结。

## 0. 标注责任与防止评价污染

允许 Codex 从原文做 AI 初标，保存到 `eval/annotations/aq-ai-v1/`，不得冒称人工真值。
用户可采用两条路径：

- 开发阶段直接使用 AI 初标，报告只能称“与 AI 参考标注的一致率”，不能冒充真实精确率/召回率。
- 要满足 FR-016 的人工真值要求，人工须对照完整选定范围的原文，补漏、纠错、裁定疑义后签名冻结。
  只确认 AI 列出的正例或抽查少量样本，不能证明其余文本标注完整；抽查只能报告抽查结果。

初标不得读取被测 Qwen 的输出。冻结验收集不可作为 prompt 调优集；冻结不等于防止泄漏，
看着冻结答案调优仍会污染评价。开发与验收语料须隔离；若用本书调优，需另设未用于调优的验收范围。
允许先冻结全书 AI 稿作为候选快照，但 `frozen_for_acceptance=false`，人工复核后才发布人工版本。

## 1. 标注范围

标可区分的故事人物之间、有原文支持的关系；允许有明确身份的无名角色（如某人的母亲），
不把群体或无法稳定区分的路人混成一个人物。所有排除/疑义均记录，避免悄悄漏标。
引文、假例、幻想、否定、传闻或不可靠自述不得直接当作已发生事实；疑义交人工裁定。
人物身份的普通上下文理解不等于要求被测系统实现完整指代消解；后者漏抽仍计入真实 FN。

**漏标并非“压低召回率”**：遗漏真关系会改变分母，可能高估召回率，并把正确预测误算为 FP。
因此不确定项须留清单，不能简单“不标就算没有”。

## 2. 封闭关系集合

| 类型 | 含义 | 方向 |
|---|---|---|
| 雇佣 | 雇主让另一人工作 | 雇主→被雇者 |
| 亲属 | 明确血缘/婚姻/宗族关系，不补推亲等 | 无向 |
| 同乡邻里 | 明确邻居或同乡，不凭共同出场推断 | 无向 |
| 冲突 | 争吵、互殴、明确不和 | 无向 |
| 欺凌 | 单方羞辱、欺负、暴力 | 施加者→承受者 |
| 追求 | 明确求爱/求亲行为；性骚扰不得自动归为求爱 | 追求者→被追求者 |
| 权势压迫 | 借身份/地位施加控制或剥夺 | 施加者→承受者 |
| 同伙 | 明确共同活动、合作或共谋；共同出现/逃跑不算 | 无向 |

同一证据允许多标签，但每个类型必须有独立语义依据；欺凌不自动再复制为冲突。
集合外关系记在 `issues.jsonl` 的 `out_of_scope`，不使用一个可规避误报的 `其他` 输出类型。
模型输出不在集合内，按 FR-009 整次拒绝；其调用和失败仍记账。
类型集只适用于此次实验；不能从八类覆盖推断已概括一本书的全部人物关系。

## 3. 人物与别名

每个人有稳定的书内 canonical_name/ID；称谓依赖上下文，不可全局按同字串强合。
确认的别名需要段落依据。繁简字对应可作为明确的规范名映射，不修改引用原文。

实际反例：C01P010 仅确认 `阿Quei` 与 `阿Q`，明确说 `阿桂` / `阿貴` 无佐证；
`老Q` 的证据在 C07P017～018。`赵太爷` 与其儿子 `赵秀才/茂才公` 不可合并。
`审讯光头老人` 与 `把总` 无明确同一身份依据时分别保留。
旧版示例段落号并非标注真值，不能复制当作完成数据。

## 4. 出处与叙述顺序

每条记录保存原样引用、段落 ID、章节和全部支持位置。网页杂项不得进入抽取。
同章同一三元组可聚合证据，但不得跨章抹掉位置；同章旧关系/新关系不同类型仍分别保存。
重叠块重复输出同一证据只计一次。回叙属于本章叙述，不声称是另一个新发生事件。
跨段证据须全部列出；无法提供支持关系语义的原文，不因“字符串存在”就判对。

## 5. 主指标（人工冻结之后）

主统计单位是 `(书版本, 章节, 规范主体, 类型, 规范客体)`；无向关系按实体 ID 排序。
真值中同单位多处支持汇总为证据集合，保留所有原始记录用于检查同章叙述变化。
预测也先按相同单位去重；同单位若含多个引用，记录有效与无效证据数。

一对一匹配 TP 必须满足实体、类型、方向、章节一致，且至少一个完整证据组支持该关系：
引用精确匹配仅为第一层；还须与已标注支持范围相符。预测发现未标注的新证据须盲审裁定，
不得自动判 FP 或暗改原真值；修订数据版本后对所有模型统一重算。

- Precision = TP / (TP + FP)，Recall = TP / (TP + FN)；分母零报 N/A。
- 失败块不能从召回分母删除，其所在范围的真关系仍计 FN。
- 有效引用率另报：正确支持关系的唯一引用数 / 所有唯一预测引用数，避免一个正确引用掩盖附带错误。
- 别名误合并数与未归一数单独报告；不得用人工别名表偷偷修好系统输出再称端到端成绩。
  使用真值别名辅助映射的“关系抽取条件指标”必须另标，不能替代别名功能验收。
- 有争议范围在发布人工真值前裁定；若保留未裁定项，明确排除单位与数量，指标不能称全书完整验收。

## 5.1 ⚠️ 本语料的已知局限（必须写进报告，不得省略）

**《阿Q正传》里大量人物互动的对方是非具名群体**——「闲人」「看客」「众人」「一群人」。
按 §1「不把群体或无法稳定区分的路人混成一个人物」，这些互动**一条都不进真值集**。

实测后果（基于 `aq-ai-v1` 初标，58 条候选）：

| 现象 | 数字 |
|---|---|
| 第 2 章《優勝記略》——全章写阿Q挨打与精神胜利 | **只有 2 条**关系，且都是别人家的父子关系 |
| 亲属类型占比 | **21/58 ≈ 36%**，是最容易从表面识别的类型 |
| 不同三元组 | 39 个（58 条含跨章重复） |

**这是选材本身的问题，不是标注质量问题。** 挑这本书时看重的是"短、人物少"，
但**"人物少"恰恰意味着大量互动没有具名对手**——这一点在选材时没被预见到。

### 对指标的影响（三条都要在报告里说）

1. **分母偏小 → 指标抖动大。** 几十个单位的量级上，一两条判断差异就会让百分比明显移动。
   报告里**必须同时给出绝对数（TP/FP/FN 的条数），不能只给百分比**。
2. **类型分布偏向"好抽的"。** 亲属占三分之一以上，而欺凌/权势压迫需要理解语义。
   总体精确率会被亲属这一类拉高，**按类型分别报告是必须的，不是可选的**。
3. **覆盖面不代表这本书。** 本真值集只覆盖**具名人物之间**的关系，
   而这本书的核心冲突（阿Q与未庄群体）恰恰落在覆盖之外。
   报告**不得**声称"在《阿Q正传》上达到 X% 精确率"，只能说
   "在《阿Q正传》**具名人物关系**这个子集上"。

### 为什么不把群体当成实体补进来

评估过并**否决**：把「闲人」「众人」当作一个具名实体，会让分母厚实很多、也更贴近这本书。
但它会引入一个**边界无法稳定判定**的实体——第 2 章的"闲人"和第 3 章的"闲人"是不是同一批？
按 §3「称谓依赖上下文，不可全局按同字串强合」，这个问题没有可靠答案。
**用一个判定不稳的实体去撑大分母，换来的数字比小分母更不可信。**

保持口径干净、如实披露局限，是这里唯一诚实的做法。
